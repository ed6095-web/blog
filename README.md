# 📌 Overview

Wavvy is a modern full-stack blogging platform designed for creators, developers, and writers who want a smooth, elegant, and interactive publishing experience.

The platform focuses on:

* Beautiful UI/UX
* Fast performance
* Clean writing experience
* Modern authentication
* Interactive blogging features
* Community-driven engagement
* Responsive design across all devices

Unlike traditional blogging platforms that feel outdated and heavy, Wavvy aims to create a lightweight, visually immersive, and social blogging ecosystem.

# 🚀 Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/ed6095-web/blog.git
```

## 2️⃣ Navigate Into Project

```bash
cd blog
```

## 3️⃣ Install Dependencies

```bash
npm install
```

---

# 🔑 Environment Variables

Create a `.env.local` file in the root directory.

```env
MONGODB_URI=
NEXTAUTH_SECRET=
NEXTAUTH_URL=
CLOUDINARY_CLOUD_NAME=
CLOUDINARY_API_KEY=
CLOUDINARY_API_SECRET=
```

---

# ▶️ Run Development Server

```bash
npm run dev
```

Open:

```bash
http://localhost:3000
```

---

# 🏗️ Build For Production

```bash
npm run build
```

Run production server:

```bash
npm start
```
